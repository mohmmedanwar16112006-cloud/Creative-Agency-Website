Creative Agency Website

A responsive Creative Agency website built using HTML and CSS.

Project Overview

This project is a front-end website for a creative agency, featuring multiple sections to showcase services, portfolio, team members, pricing plans, and contact information.

Features

- Home section
- About section
- Portfolio section
- Services section
- Pricing section
- Team section
- Blog Post Page
- Contact section

Technologies Used

- HTML
- CSS

Project Structure

- "index.html" – Main website page
- "Blog-post.html" – Blog post page
- "style.css" – Stylesheet file
- "images/" – Project images
